# Phase 1 — Correctness Fixes (Complete)

Implements the "P1 — Correctness" phase from `REVIEW_RESPONSE.md`. No new
features were added; this phase removes defects that made any later
confidence, risk or validation claim indefensible.

## What changed

| File | Change |
|---|---|
| `preprocessing.py` | **New.** Single source of truth for cleaning + validation. Defines `FEATURE_COLS`, `AQI_LABELS`, `validate_reading`, `preprocess_dataframe`, `features_from_reading`. Used by both training and inference. |
| `bootstrap_tf.py` | **New.** Import-order shim that loads TensorFlow before pandas to avoid a macOS deadlock. |
| `predictors.py` | Removed the hardcoded `pm25 = 25.0` feature. Models now use the 3 measurable channels. Class labels are mapped via `model.classes_`, so non-contiguous label sets can no longer be silently mislabelled. Reads the schema from `model_metadata.json`. Invalid readings return an explicit error instead of a fake prediction. |
| `train_model.py` | Runs training data through `preprocessing`. PM2.5 dropped from features. **Chronological** split instead of a random shuffle. Writes honest metrics + schema to `model_metadata.json`. |
| `train_lstm.py` | Runs preprocessing, fits the scaler on the **training split only** (removes leakage), chronological validation split, class count derived from the data. |
| `dashboard.py`, `dashboard_v2.py`, `backend/main.py` | Import `bootstrap_tf` first. |
| `tests/test_preprocessing.py` | **New.** Locks in the feature schema, label space and preprocessing behaviour. |
| `README.md` | Documents the feature contract and import-order constraint; corrects the "confidence %" wording and the file tree. |

## Defects closed

1. **Frozen feature removed.** Every prediction previously passed `pm25 = 25.0` (`predictors.py:77`, `predictors.py:123`). The models now use only `temp`, `hum`, `gas` — the same schema at train and serve time.
2. **Label space unified.** One canonical `AQI_LABELS` map (0–5) is used everywhere; predictions are decoded through `model.classes_`.
3. **Time-series leakage removed.** RF/LR now use a chronological split; the LSTM scaler is fitted on training data only.
4. **LSTM deadlock fixed.** Import order (`bootstrap_tf.py`) resolves the macOS pandas-before-TensorFlow hang that stalled `fit`/`predict`.

## Honest current metrics (from `model_metadata.json`)

| Model | Metric | Value |
|---|---|---|
| Random Forest | accuracy (chronological test) | 70.8% |
| Linear Regression | RMSE / MAE / R² | 27.66 / 20.99 / 0.118 |
| LSTM | validation accuracy | 71.9% |

These are deliberately reported as-is. They are weak because the training data
itself is weak, not because the code is:

* `real_air_data.csv` has **768 hourly rows** (the panel's "769" included the header).
* Its `gas` column is **synthetic** — generated by `estimate_gas_from_pollutants()`.
* Its `temp` and `hum` columns are **constant** (25.0 / 50.0) because the API's
  weather fields were null and defaulted, so the models never saw real
  temperature or humidity.

Phase 2 (calibration + real data collection) is what moves these numbers.
